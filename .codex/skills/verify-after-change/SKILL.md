# 项目变更验证

每次修改代码后都使用此 Skill。不要先在沙箱内试跑验证命令；直接申请沙箱外权限执行编译和测试。

## 必须执行

按顺序运行以下两组验证。第一组是编译/检查，第二组是测试。

### 1. 编译

后端 Go 编译：

```bash
go test -run '^$' ./...
```

后台管理前端检查与构建：

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm check
pnpm build
```

前端命令必须在 `admin` 目录下运行。

### 2. 测试

运行后端测试：

```bash
go test -p 1 ./...
```

测试命令必须在项目根目录运行。

如果本机没有可用 PostgreSQL 测试库，先说明阻塞原因；不要跳过 `go test -p 1 ./...`。

## 执行要求

- 如果某一步失败，保留失败输出的关键错误，修复后重新从相关失败步骤开始验证。
- 最终回复必须说明编译和测试是否都已运行，以及失败时的具体阻塞点。
